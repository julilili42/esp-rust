# Master Slave / Controller Target Paradigm:

One MCU (Microcontroller Unit) coordinates autonomously when its peripherals can send or receive data.

# SPI

Uses Master Slave Paradigm.
Communication is synchrounsly over one bus. Every peripheral communicates by using a central clock.
Four physical connections:

- SCLK (Serial clock) -> Generated by the MCU
- COPI (Controller out peripheral in) -> Data connection from MCU to peripheral
- CIPO (Controller in peripheral out) -> Data connection from peripheral to MCU
- CS (Chip select) -> Connection to select per peripheral

All peripherals are connected over a bus to the MCU.
All CS connections are HIGH (inactive). The clock SCLK is also constant LOW or HIGH (inactive).
The MCU picks a CS connection to a peripheral and sets it LOW.
The MCU starts the clock signal SCLK.
Full Duplex data transfer begins.
Clock stops.
CS connection set to HIGH.

For each peripheral we need to use a seperate CS connection (GPIO pins can be used as CS connection).

# I^2C

Uses Master Slave Paradigm.
Does not need a seperate CS connection. Only 2 wires.
Uses Adresses to connect to peripherals (f.ex 0x3C). Uses 7 Bits -> 128 possible addresses.
Each peripheral shares:

- SCL (Serial Clock) -> Clock generated by the MCU
- SDA (Serial Data) -> Shared half duplex data connection (at each point data is transferred in one direction).
